One row per assessment recorded for the party and component. `facts` are the source records the assessment cites, each a reference of the form `schema.table:key`. Where a determination in the latest schedule rests on the assessment, its outcome, rate and the clearance it relies on are given; the other rows are the rule versions that were tested and set aside.

The assessments and the schedule are what the last run of WF3 recorded. Before any run there are none, and the answer is that no assessment is on record, not that no rule applies. No obligation record is written by WF3: the withholding determination and its assessment stand for the obligation.

# Computation

```sql
SELECT a.assessment_id AS assessment, a.evaluates_rule AS rule, a.evaluates_version AS version, v.rule_name, v.rate_pct AS rule_rate,
       (SELECT array_agg(s.citation ORDER BY s.authority_id) FROM rulebook.rule_authority ra JOIN rulebook.authority_source s USING (authority_id)
        WHERE ra.rule_id = a.evaluates_rule AND ra.version_label = a.evaluates_version) AS authorities,
       a.assessment_result AS result, a.reasoning,
       (SELECT array_agg(f.source_ref ORDER BY f.source_ref) FROM clearance.assessment_fact f WHERE f.assessment_id = a.assessment_id) AS facts,
       d.determination_id AS determination, d.determination_outcome AS outcome, d.withholding_rate AS rate, d.relies_on_clearance,
       'clearance.obligation_assessment:' || a.assessment_id AS source_ref
FROM clearance.obligation_assessment a
JOIN rulebook.rule_version v ON v.rule_id = a.evaluates_rule AND v.version_label = a.evaluates_version
LEFT JOIN clearance.withholding_determination d ON d.supported_by = a.assessment_id
 AND d.schedule_id = (SELECT max(schedule_id) FROM clearance.withholding_schedule)
WHERE a.subject_party = %(party_no)s AND a.subject_event = %(component_id)s
ORDER BY d.determination_id NULLS LAST, a.assessment_id
```
