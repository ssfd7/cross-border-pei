Walks the holdings valid on the date upwards from the company through the entities of the fund's own structure. `segment` is `fundToCompany` from the company up to and including the first fund vehicle reached, and `aboveFund` for the structure entities that hold that fund. Investors that are not structure entities are not on this chain; their jurisdictions are in the investor register and the onboarding record.

Every entity has a row for incorporation and for tax residence. Where `recorded` is false the capacity has no row in the source: it is unknown, not absent, and must be reported as unknown. An operating location appears only where one is recorded.

# Computation

```sql
WITH RECURSIVE chain (entity_id, tier, above_fund, path) AS (
    SELECT e.entity_id, 0, false, ARRAY[e.entity_id]
    FROM entity_mgmt.legal_entity e WHERE e.entity_id = %(company_id)s
    UNION ALL
    SELECT s.owner_entity_id, c.tier + 1, c.above_fund OR owned.is_fund = 'Y', c.path || s.owner_entity_id
    FROM chain c
    JOIN entity_mgmt.legal_entity owned ON owned.entity_id = c.entity_id
    JOIN entity_mgmt.shareholding s ON s.owned_entity_id = c.entity_id
     AND s.eff_from <= %(on_date)s::date AND (s.eff_to IS NULL OR s.eff_to >= %(on_date)s::date)
    WHERE s.owner_entity_id <> ALL (c.path)
), entity AS (
    SELECT entity_id, min(tier) AS tier, bool_and(above_fund) AS above_fund FROM chain GROUP BY entity_id
), wanted (entity_id, capacity_cd) AS (
    SELECT entity_id, capacity FROM entity CROSS JOIN (VALUES ('INC'), ('TAXRES')) AS c (capacity)
    UNION
    SELECT j.entity_id, 'OPS' FROM entity_mgmt.entity_jurisdiction j JOIN entity USING (entity_id) WHERE j.capacity_cd = 'OPS'
)
SELECT e.entity_id AS entity, l.legal_name AS name, e.tier,
       CASE WHEN e.above_fund THEN 'aboveFund' ELSE 'fundToCompany' END AS segment,
       CASE w.capacity_cd WHEN 'INC' THEN 'incorporation' WHEN 'TAXRES' THEN 'taxResidence' ELSE 'operatingLocation' END AS capacity,
       j.country, j.subdivision, j.country IS NOT NULL AS recorded,
       'entity_mgmt.entity_jurisdiction:' || j.entity_id || '/' || j.capacity_cd || '/' || j.country || '/' || j.from_dt AS source_ref
FROM entity e
JOIN entity_mgmt.legal_entity l ON l.entity_id = e.entity_id
JOIN wanted w ON w.entity_id = e.entity_id
LEFT JOIN entity_mgmt.entity_jurisdiction j ON j.entity_id = w.entity_id AND j.capacity_cd = w.capacity_cd
 AND j.from_dt <= %(on_date)s::date AND (j.to_dt IS NULL OR j.to_dt >= %(on_date)s::date)
ORDER BY e.tier, e.entity_id, w.capacity_cd, j.country
```
