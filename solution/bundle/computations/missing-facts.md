A finding is either an open item of a clearance, recorded when the investor was admitted or its clearance withdrawn, or a gap an assessment found when a rule version could not be decided. `found_by` says which. The same missing fact can appear once as each; they are separate records and are not merged here.

Findings from assessments are what the last run of WF3 recorded.

# Computation

```sql
SELECT m.finding_id AS finding, m.about_party, i.display_name AS party_name,
       m.unmet_requirement AS requirement, r.description AS requirement_text, r.rule_id AS rule, r.version_label AS version, r.mandatory,
       m.description, m.recorded_on,
       CASE WHEN m.clearance_id IS NOT NULL THEN 'clearance' ELSE 'assessment' END AS found_by,
       m.clearance_id AS clearance, c.clearance_status, m.assessment_id AS assessment, a.subject_event AS component,
       'clearance.missing_fact_finding:' || m.finding_id AS source_ref
FROM clearance.missing_fact_finding m
JOIN rulebook.fact_requirement r ON r.req_id = m.unmet_requirement
LEFT JOIN investor_register.investor i ON i.inv_no = m.about_party
LEFT JOIN clearance.clearance c ON c.clearance_id = m.clearance_id
LEFT JOIN clearance.obligation_assessment a ON a.assessment_id = m.assessment_id
ORDER BY m.about_party, m.finding_id
```
